## Changes

- **Limits and import safety** (`lib/validate.ts`, `lib/migrate.ts`, `hooks/usePaintingLog.ts`, `components/PaintLogApp.tsx`)
  - Names are limited to 120 characters (`MAX_NAME_LENGTH`), alongside the count limit of 199.
  - `migrate` is now built on `migrateWithReport`. It lowers over-limit counts and shortens over-long names instead of rejecting the data, reports whether it did, and returns items with only their known fields, so unknown properties are no longer persisted.
  - It returns validated data, so the second `isAppState` check in the hook and in the import code is gone.
  - When loading changes any value, the original data is copied to `painting-log-state.bak` (or `.bak.2` and so on) and a dismissible notice names the copy. Cleared by "Start fresh".
  - Importing keeps a copy of the current stored data first. If a copy is needed and cannot be saved, the import is refused with a message and nothing is replaced. The confirmation says a copy is kept and warns when the file has values over the limits.
- **Download helper** (`lib/download.ts`, `components/PaintLogApp.tsx`, `app/error.tsx`)
  - One `downloadFile` replaces the two copies. It revokes the object URL after a one second delay rather than straight after the click, which can cancel the download in Safari, and it attaches the link to the page for the click, which older Firefox needs.
- **Headings, error boundary and touch targets** (`components/Sidebar.tsx`, `components/ProjectList.tsx`, `components/icons.tsx`, `app/error.tsx`, `app/global-error.tsx`)
  - "Painting Log" is the page `h1`. The category title is `h2`, the project heading `h3`, "No Projects Found" `h3`, and the welcome screen's heading stays `h2`.
  - The empty-state illustration is one shared `EmptyBoxIcon`. The "Blob, Blob" comment is fixed.
  - `app/error.tsx` marks only its message as an alert, not the buttons. New `app/global-error.tsx` gives root-layout errors a boundary.
  - Sidebar chevron, rename and delete buttons grow from about 24px to 32px. The model table is left compact on purpose.
  - The duplicate category name check treats Unicode-equivalent names as the same, using NFC normalisation and plain `toLowerCase()` (N7). `toLocaleLowerCase()` was avoided on purpose, because it varies with the browser locale (Turkish dotless i).
- **CI** (`.github/workflows/ci.yml`): `npm audit --audit-level=high` now covers dev dependencies too (N12). It reports 0 vulnerabilities. This is a deliberate trade-off: a high advisory in dev tooling alone can turn CI red, and it has to be fixed or acknowledged.
- **Test hygiene** (`vitest.setup.ts`, `components/PaintLogApp.test.tsx`): mounted components and hooks are unmounted after every test, so listeners no longer leak between tests, and the export test restores `URL` properly (N13).
- **Docs**: README documents the limits, the import copy and the new notice. The 2211 note says it is partly superseded, and the 2320 note records that `next build` passes.
