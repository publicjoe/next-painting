# Fix the two High QA findings

Date: 2026-10-24 23:35

## Summary

This commit also adds the second QA review, `docs/qa/2026-10-24-2329-qa-review.md`, with H1 and H2 marked as fixed and a section recording the re-review of these fixes.

Fixes H1 (unreadable data and the backup) and H2 (keyboard focus lost after a delete) from `docs/qa/2026-10-24-2329-qa-review.md`.

## Changes

- **H1: backup honesty and "Start fresh" safety** (`hooks/usePaintingLog.ts`, `components/PaintLogApp.tsx`)
  - A new `keepBackup` helper never overwrites an earlier backup. It uses the first free key out of `.bak`, `.bak.2` and so on, and reuses a key that already holds identical data.
  - If the backup cannot be written, the banner now says so instead of claiming a copy was kept. The hook returns `backupKey` (null when no copy exists).
  - The hook also returns `backupFailed`, so the dialog can tell a failed backup apart from storage that could not be read at all (no backup attempted, data may still be there).
  - "Start fresh" now opens a confirmation dialog. The text names the backup key, or warns that nothing can be recovered when no backup exists.
- **Shared backup code** (`lib/backup.ts`, `app/error.tsx`, `hooks/usePaintingLog.ts`)
  - `BACKUP_KEY` and `keepBackup` moved into `lib/backup.ts`. The hook and the error boundary both use them, which removes the duplicated key.
  - The error boundary's "Reset data" no longer overwrites `.bak`. If no backup can be written it clears nothing and says so, instead of destroying the only copy.
- **H2: focus after a delete** (`components/UndoToasts.tsx`, `components/PaintLogApp.tsx`)
  - A new delete toast moves focus to its Undo button. A toast pauses while it is hovered or holds focus (tracked separately, so the pointer leaving cannot restart the timer under keyboard focus), and times out only after both end.
  - Confirming "Start fresh" also returns focus to the main area, because the banner that held the button is removed.
  - Focus only moves to Undo when the delete was a keyboard activation (a click with `detail` 0, tracked in `PaintLogApp`). A mouse delete leaves focus alone.
  - The main area shows a focus ring (inset) when focused programmatically, instead of hiding it.
  - Toasts gain a Dismiss button. Undo and Dismiss hand focus to the main area (`tabIndex={-1}`) so it never falls to the page body.
